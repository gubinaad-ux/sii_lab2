## Требования

- Python 3.8+
- Библиотека tkinter (входит в стандартную поставку Python)

## Файлы

- Sii_lab2.py — основной код программы
- rules.txt — база правил (отдельный текстовый файл)
- README.txt — этот файл

## Как запустить

1. Склонировать репозиторий или скачать файлы.
2. Убедиться, что Sii_lab2.py и rules.txt лежат в одной папке.
3. Открыть терминал в этой папке.
4. Выполнить:
python Sii_lab2.py
